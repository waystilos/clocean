# Bugs and Feature Feedback

Clocean is currently maintained by a small core team. We are listening to bug reports and feature ideas, but we are not accepting code contributions or pull requests at this time. We may revisit the contribution policy as the project matures.

## Report a bug

Please [open an issue](https://github.com/waystilos/clocean/issues/new) and include:

- What you expected to happen
- What happened instead
- The steps needed to reproduce the problem
- Your browser, device, and operating system
- Whether the issue occurs locally or in the deployed Cloudflare environment
- Relevant console or Worker errors, with credentials, tokens, email addresses, and private workspace data removed

Screenshots, short recordings, and a minimal reproduction are helpful when the issue involves the interface or a particular file type.

## Suggest a feature

Feature ideas are welcome through the same [issue tracker](https://github.com/waystilos/clocean/issues/new). Please describe the problem the feature would solve and how you expect it to work. This helps us evaluate ideas even when we cannot implement them immediately.

## Security issues

Do not include exploitable details, credentials, access tokens, private files, or personal data in a public issue. For a security concern, use the repository's private security reporting channel when available or contact the project maintainer directly before publishing details.

## Contribution policy

Code contributions, pull requests, and unsolicited patches are paused for now. Please use bug reports and feature feedback to share improvements while this policy is in place.
